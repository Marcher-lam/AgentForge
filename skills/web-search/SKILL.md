# Web Search Skill

When asked to search for information:

1. Formulate a clear, specific search query
2. Use the search tool to find relevant results
3. Synthesize information from multiple sources
4. Cite sources with URLs
5. Distinguish between facts and opinions

Use the `skill_web-search` tool with `{"input": "<search query>"}` to invoke.
